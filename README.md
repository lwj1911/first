# TodoList

一个使用 React + Vite 开发的 TodoList 项目。

## 功能

* 添加待办事项
* 删除待办事项
* 编辑待办事项
* 完成状态切换
* 搜索 Todo
* Todo 筛选
* 动画效果
* JSON Server 模拟后端

---

## 技术栈

* React
* Vite
* JavaScript
* CSS
* Fetch API
* JSON Server

---

## 项目启动

### 安装依赖

```bash
npm install
```

### 启动 React 项目

```bash
npm run dev
```

默认运行：

```txt
http://localhost:5173
```

---

## JSON Server

后端使用 JSON Server 模拟。

启动方式：

```bash
json-server db.json --port 3001
```

接口地址：

```txt
http://localhost:3001/todos
```
